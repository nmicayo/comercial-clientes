# Regras de Score

A pontuação serve para classificar empresas por potencial comercial logístico.

## Regra principal

O maior peso da análise deve estar na evidência de operação recorrente com produto físico.

Isso vale mais do que marca forte, presença digital ou tamanho percebido da empresa. Nesta fase, score alto deve ser consequência de sinais concretos de operação física.

## Pontos positivos

| Critério | Pontos |
|---|---:|
| É distribuidora solar | +30 |
| Vende para integradores | +25 |
| Trabalha com kits solares | +20 |
| Trabalha com módulos ou inversores | +20 |
| Menciona pronta entrega | +20 |
| Menciona estoque ou centro de distribuição | +25 |
| Entrega para todo o Brasil | +20 |
| Atua em SP, Sudeste ou regiões relevantes | +15 |
| É revenda de material elétrico com linha solar | +15 |
| Possui e-mail comercial público | +5 |
| Possui WhatsApp comercial público | +5 |

## Pontos negativos

| Critério | Pontos |
|---|---:|
| Não atua com produto físico | -30 |
| Atua apenas com assinatura de energia | -10 |
| Parece empresa muito pequena/local | -10 |
| Não tem canal comercial claro | -10 |
| Não tem relação com solar/distribuição | -40 |
| É marketplace puro sem operação física aparente | -15 |
| É operação de financiamento sem sinal logístico claro | -15 |
| Atua apenas em geração compartilhada sem operação física evidente | -15 |

## Classificação final

| Score | Potencial |
|---:|---|
| 0 a 39 | Baixo |
| 40 a 69 | Médio |
| 70 a 100+ | Alto |

## Ajustes de julgamento

- Se houver sinais fortes de estoque, expedição e distribuição, o lead pode subir de faixa mesmo com pouca informação institucional
- Se houver apenas narrativa de ecossistema, assinatura, plataforma ou intermediação, a empresa deve ficar em faixa mais baixa
- Proximidade de Cabo de Santo Agostinho, Maringá e Barueri/Alphaville aumenta relevância, mas não substitui evidência de operação física

## Pontuação adicional — potencial de armazenagem

Use esta camada quando o lead já tiver score de transporte calculado.
Serve para identificar quais leads também têm perfil de contrato fixo de armazenagem.

### Pontos positivos (armazenagem)

| Critério | Pontos |
|---|---:|
| Distribuidora solar com cobertura multi-regional ou nacional | +35 |
| Menciona entrega em múltiplos estados | +25 |
| Não menciona galpão, CD ou estrutura própria de armazenagem | +20 |
| Crescimento recente ou expansão declarada | +15 |
| Atua nas 3 praças das filiais Phenyx (PE, PR, SP) | +20 |
| Volume aparente de equipamentos (módulos, inversores, kits) | +15 |
| Referência a pronta entrega sem evidência de estrutura própria | +15 |

### Pontos negativos (armazenagem)

| Critério | Pontos |
|---|---:|
| Menciona CD próprio ou galpão em múltiplas regiões | -25 |
| Empresa muito local (atua só em uma cidade) | -20 |
| Volume aparentemente pequeno (instaladora residencial, por exemplo) | -15 |

### Classificação de potencial de armazenagem

| Score armazenagem | Potencial |
|---:|---|
| 0 a 29 | Baixo — foco só em transporte |
| 30 a 59 | Médio — vale explorar na abordagem |
| 60+ | Alto — perfil de contrato fixo |
